# Редизайн лендинга нотариуса: «солидный нотариат»

Смена визуального языка сайта с SaaS-шаблона (синие градиенты, прыгающие анимации) на спокойный юридический стиль: тёмно-синий + золото/бежевый, serif-заголовки, мягкие тени вместо градиентов. Дополнительно — mobile-first проработка, hero с CTA-кнопками, блок доверия и FAQ-аккордеон.

Структура секций сохраняется: Header → Hero → Доверие → Услуги → FAQ → Расположение → Форма → Footer.

Параллельно — смена контактных данных: город меняется с Тараза на Караганду, вместе с адресом, телефоном, графиком работы и всей SEO-обвязкой.
